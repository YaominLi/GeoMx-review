# MSigDB inputs

Place these MSigDB 2025.1 human gene-symbol GMT files in this directory:

- h.all.v2025.1.Hs.symbols.gmt
- c2.all.v2025.1.Hs.symbols.gmt
- c5.all.v2025.1.Hs.symbols.gmt
- c7.all.v2025.1.Hs.symbols.gmt

Obtain the versioned files from MSigDB through its normal access process. They are not bundled in the code distribution. The exact reviewed file hashes are in `environment/input_checksums.csv` at the project root. A newer collection with a similar name is a different analysis input.
